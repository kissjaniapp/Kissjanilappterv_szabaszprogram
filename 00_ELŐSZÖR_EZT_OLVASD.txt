LAPTERV — EGY LÉPÉSBEN FELTÖLTHETŐ GITHUB PROJEKT (0.2.0)

A projekt GitHub-repositoryja már létezik:
https://github.com/kissjaniapp/Lapterv-Windows

1. Nyisd meg a GITHUBRA_FELTOLTENDO mappát (EBBEN VAGY MOST).
2. Nyomj Ctrl+A-t, hogy az ÖSSZES itteni fájl és mappa ki legyen jelölve.
3. GitHub → Lapterv-Windows → Code → uploading an existing file vagy Add file / Upload files.
4. Az egész kijelölést EGYSZERRE húzd a GitHub feltöltési területére.
5. Ellenőrizd, hogy a GitHub a következő útvonalat mutatja:
     .github/workflows/lapterv-windows.yml
   (A .github egy mappa, ezt a helyén kell hagyni.)
6. Kattints: Commit changes (main).
7. Actions → Lapterv - Windows telepito automatikus epites.
8. A sikeres futás Artifacts részénél töltsd le a telepítő ZIP-et.

NEM kell almappákat megnyitni, NEM kell fájlokat áthelyezni,
NEM kell egyesével feltöltögetni.

FIGYELEM: A .xPrg export még nincs gépre hitelesítve.
A Windows próbaverzió nem ad ki valódi végrehajtható .xPrg programot.
